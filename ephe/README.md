`sefstars.txt` is the Swiss Ephemeris fixed-star catalogue (Astrodienst; the file's own header records its provenance and editing history), copied UNMODIFIED on 2026-09-11 from the `kerykeion` package (version 5.12.9, `kerykeion/sweph/sefstars.txt`), which redistributes it under AGPL-3.0 -- the licence this app carries (`LICENSE`). It is the only ephemeris file shipped: the planets stay on the built-in Moshier ephemeris (no `.se1` file is bundled or needed). Swiss Ephemeris is never pointed at this directory: the engine checks the file against the SHA-256 it records (`FIXED_STAR_CATALOGUE_SHA256` in `engine.py`) and reads a copy of it from a private folder of its own, the only folder Swiss Ephemeris is given. A changed file here is refused, not read, and nothing else placed here is opened; replacing the catalogue means recording its new hash with it (see `_fixed_star_catalogue_search` in `engine.py` and `docs/BUILD_NOTES.md`).
